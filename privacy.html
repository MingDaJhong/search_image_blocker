隱私權政策

Search Image Blocker  ·  最後更新：2026 年 5 月

我們收集什麼資料？

本擴充功能不收集任何個人資料，也不會向任何外部伺服器傳送任何資訊。 所有設定（關鍵字清單、分類、封鎖類型）均儲存於您瀏覽器的 chrome.storage.sync，由 Google 跨您已登入的 Chrome 裝置同步， 不經過本擴充功能的伺服器。

我們如何使用資料？

設定資料僅用於在 Google 搜尋頁面上執行封鎖邏輯，完全在您的裝置上處理，不離開瀏覽器。

第三方服務

本擴充功能不整合任何分析、廣告或遙測服務。

權限說明

storage：用於儲存您的設定。
主機權限（Google 搜尋頁，涵蓋 16 個地區網域：google.com、 google.com.tw、google.com.hk、google.co.jp、google.co.kr、google.com.sg、 google.co.uk、google.com.au、google.ca、google.co.in、google.de、 google.fr、google.es、google.it、google.com.br、google.com.mx）：用於在 Google 搜尋結果頁面注入封鎖用的 CSS 規則。

聯絡方式

如有隱私權相關疑問，請至 GitHub Issues 提出。

Privacy Policy

Search Image Blocker  ·  Last updated: May 2026

What data do we collect?

This extension collects no personal data and transmits nothing to any external server. All settings (keyword lists, categories, block types) are stored in your browser's chrome.storage.sync, which Google syncs across your signed-in Chrome devices. This sync is handled entirely by Google and does not pass through any server operated by this extension.

How do we use data?

Settings are used solely to run blocking logic on Google Search pages. All processing happens on your device and never leaves the browser.

Third-party services

This extension does not integrate any analytics, advertising, or telemetry services.

Permissions explained

storage: to persist your settings.
Host permissions (Google Search across 16 regional domains: google.com, google.com.tw, google.com.hk, google.co.jp, google.co.kr, google.com.sg, google.co.uk, google.com.au, google.ca, google.co.in, google.de, google.fr, google.es, google.it, google.com.br, google.com.mx): to inject CSS blocking rules into Google Search result pages.
